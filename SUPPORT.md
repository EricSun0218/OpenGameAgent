# Support

OpenGameAgent is currently an Alpha project maintained on a best-effort
basis. There is no guaranteed response time or commercial support entitlement
for the open-source repository.

Use the following channel for each request:

- reproducible bugs: open a bug report;
- feature proposals and API changes: open a feature request;
- integration questions and usage help: use GitHub Discussions;
- suspected vulnerabilities: follow [SECURITY.md](SECURITY.md) and never open a
  public issue;
- community participation: follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Maintainers prioritize security regressions, data corruption, duplicate side
effects, compatibility regressions in verified engine targets, and failures in
documented release gates. Include the smallest reproduction, exact Runtime and
engine versions, placement mode, provider dialect, and relevant sanitized logs.

Only the versions listed in [SECURITY.md](SECURITY.md) receive security fixes.
Compatibility evidence and its limits are documented in
[Engine integration](docs/engine-integration.md).
