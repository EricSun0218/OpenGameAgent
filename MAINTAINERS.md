Repository access follows least privilege. Maintainer status does not imply
access to provider credentials, private vulnerability reports, package
publishing identities, or release signing unless that access is required for
the maintainer's current responsibility.

Governance and the path to maintainership are defined in
[GOVERNANCE.md](GOVERNANCE.md).
