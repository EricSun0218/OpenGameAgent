# Code of conduct

We are committed to a welcoming, respectful, and harassment-free community.

Contributors must communicate constructively, respect differing viewpoints,
accept responsibility for mistakes, and focus criticism on ideas and code rather
than people. Harassment, threats, discriminatory language, sexualized conduct,
doxxing, and sustained disruption are not acceptable in project spaces.

Project maintainers may edit, reject, or remove contributions and may restrict
participation when behavior is inappropriate, threatening, or harmful. During
the private Alpha, reports should use the invitation channel. Before public
contributions open, maintainers must publish a dedicated private conduct
contact. Vulnerability reporting is not a substitute for conduct reporting.
Maintainers will protect reporters' privacy as far as reasonably possible and
will apply these standards consistently.

This policy applies to repository activity and to public spaces where someone is
representing the project.
